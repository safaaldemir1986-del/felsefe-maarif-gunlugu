# Felsefe Maarif Günlüğü

Windows için Tauri 2 tabanlı masaüstü öğretmen uygulaması.

## Bulut derleme

Bu depodaki GitHub Actions iş akışı Windows üzerinde otomatik olarak NSIS `Setup.exe` üretir.

Derleme çıktısı GitHub → **Actions** → **Build Windows Installer** → **Artifacts** bölümünden indirilebilir.

## Uygulama bölümleri

- Yıllık Plan
- Günlük Planlar
- Performans Ödevleri ve Fikirleri
- Etkinlik Fikirleri
- Önemli Gün ve Haftalar
- Sizin Ajandanız

Profil ve ajanda verileri uygulamanın yerel depolama alanında cihazda saklanır.
